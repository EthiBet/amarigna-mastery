Fidel — The Ethiopic Alphabet

Sentence Practice

Translate freshly generated sentences using the Amharic present progressive tense. Answer in romanized Amharic, e.g. ine lij iyyefelleghu new.

Formula: iyye + [stem] + [suffix] + new  ·  Word order: Subject · Object · Verb
Suffixes: I=hu · You(m)=h · You(f)=sh · He=e · She=ech · We=en · You(pl)=achihu · They=achew — drop the leading "e" from ech/en if the stem ends in a vowel.
