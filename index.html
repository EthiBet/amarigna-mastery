Fidel — The Ethiopic Alphabet

Amharic is written in the Ge'ez script. Each symbol represents a syllable — a consonant combined with one of 7 vowels. There are 31 consonant families × 7 vowel orders = 217 core characters. Click any character to hear it spoken and see its romanization.

Vowels: ① ä = "uh" ② u = "oo" ③ i = "ee" ④ a = "ah" ⑤ ē = "ay" ⑥ ɨ = "ih" ⑦ o = "oh"

Sentence Practice

Translate dynamically generated sentences using the Amharic present progressive tense. Type answers in romanized Amharic (e.g. ine lij iyyefelleghu new).

Formula: iyye + [stem] + [suffix] + new  ·  Example: "I am going" → iyyehēdhu new  ·  Word order: Subject · Object · Verb
Suffixes: I=hu · You(m)=h · You(f)=sh · He=e · She=ech · We=en · You(pl)=achihu · They=achew  — If stem ends in a vowel, drop the leading "e" from ech/en.
